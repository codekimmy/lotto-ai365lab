  • 예산 관리: 주 5조합(5,000원) 이하

2. 조합 선택

안정형 3 + 2등 기대형 2 = 5조합(5,000원).

3. 구매 시점

목~토 오후 8시 이전. 마감 직전 혼잡 회피.

4. 기록

5. 금지

충동 구매, 대출 구매, 감정적 추가 구매 금지.

6. 장기 관점

📜 창의적 기법 사전

1~6단계 실험에서 사용된 20가지 비정형 기법.

1. 거울 번호

45 기준 대칭. 11↔34, 13↔32, 44↔1.

2. 보색 번호

45 - 번호. 거울 번호와 동일.

3. 보너스 회귀

이전 보너스 번호가 다음 회차 당첨번호로.

4. 연속번호 회귀

연속번호 다음 회차 패턴.

5. 냉각 후 반등

30회 이상 미출현 번호 반등.

6. 회차 숫자 분해

1239 → 1,2,3,9 → 12,13,19,21,23,29...

7. 날짜 숫자 분해

2026-09-05 → 2,0,2,6,0,9,0,5 → 2,5,6,9,15.

8. 인접 번호

당첨번호 ±1.

9. 끝수 분석

끝수 합, 분포, 보완 끝수.

10. 합계값 회귀

평균 135~140. 120~160 목표.

11. 홀짝 비율

홀 3~4, 짝 2~3.

12. 고저 비율

저 3~4, 고 2~3.

13. 번호대 분포

10/20/30/40번대 균형.

14. 3의 배수 보완

3의 배수 0개 다음 1~2개.

15. 소수/합성수

소수 2~3, 합성수 3~4.

16. 동시 출현 네트워크

13→18,34,38 / 20→30,40 / 44→1,14,34,45.

17. 네트워크 중심성

연결 많은 번호.

18. 군집(cluster)

중심성 높은 번호 묶음.

19. 베이지안 가중치

사전 13.33% 업데이트.

20. GA+MLP+RL

유전 알고리즘 + MLP + RL 보상.
